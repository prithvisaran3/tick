# Tick icon set

24 custom outline icons for the finance app. Files live in this folder as `<name>.svg`.

## Icons

today, activity, caught, flows, ask, plus, search, filter, arrow-in, arrow-out, calendar, bank, card, receipt, camera, briefcase, repeat, goal, bell, lock, share, trash, check, settings

## Rules

- ViewBox `0 0 24 24`, width and height `24`.
- `fill="none"`, `stroke="currentColor"`, `stroke-width="1.75"`.
- `stroke-linecap="round"` and `stroke-linejoin="round"`.
- No gradients, no text, no external references.
- Only exceptions to outline-only: tiny dots, drawn as zero-length round-capped lines or as circles with `fill="currentColor"` and r <= 1.
- Keep content inside a 2px safe margin (coordinates 2..22).
- Style: friendly, slightly rounded corners, nothing sharp, consistent optical weight, max about 6 primitives per icon.
